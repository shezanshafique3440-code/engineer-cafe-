# Client trial — 30–60 minutes

Use an agreed practice dataset. Manual bills, payments, stock changes and refunds create records; a TEST name does not automatically mark a record for demo cleanup. Review imported demo records and manually entered trial records separately before live trading. Preserve real records and reconcile posted accounting entries through supported corrections/refunds.

Record the operator, date, browser/device, test bill IDs and any issue. Let the client operate the screens without coaching; note every unclear step.

- [ ] Confirm the intended release, online database health and current PM2 services.
- [ ] Open the correct cashier's shift with counted opening cash. Prepare this browser until Offline counter ready.
- [ ] Create 10 normal sales, including add-ons and a kitchen note. Check item totals, cash/change and the physical printer.
- [ ] Follow tickets through Preparing → Ready → handover. Confirm unpaid pickup is collected once.
- [ ] Preview an unpaid/unprepared bill edit, keep the original once, then save a second edit.
- [ ] Disconnect the router/WAN while a bill is being entered. Preserve its items and cash. Save 3 offline bills, reload, reconnect and confirm one server order per bill ID.
- [ ] Check Pending sync / Needs review / Your shift labels. Review a rejected bill explicitly. Confirm cash closing stays blocked for unresolved local cash bills.
- [ ] Cancel one allowed practice order and record any actual refund. Reconcile cooked stock and refund history correctly.
- [ ] Receive one supplier purchase. Check ingredient quantity/cost and supplier payment/balance.
- [ ] Review a delivery/rider commission and any rider cash due.
- [ ] Record one employee attendance entry and review a salary draft. Employee login is optional unless the person needs system access.
- [ ] Download the required separate Excel files and Download All ZIP for the chosen Pakistan dates. Reconcile cashier, cash shift, payment/reversal and posted sales totals.
- [ ] Count actual closing cash, review other devices/table balances/rider cash and close the shift.
- [ ] Confirm both owner accounts retain full tools; counter and other staff see only granted tools.
- [ ] Verify daily backup operation, an isolated restore drill, recovery email configuration, and actual printer output before handover.
- [ ] Decide the final domain. Synchronize all old-origin offline bills first, then prepare devices again on the new origin.

Fix confusing screens, repeat failed cases, and obtain client acceptance of the remaining operational limitations before live trading. Do not clear pending browser data or perform an unreviewed database reset.
